# AI risk register — no in-scope AI system

The launch scope contains no AI/LLM feature, model, prompt processing, or external AI integration. This table does not list hypothetical model risks as if an AI system were deployed. General application threats are tracked in [the security model](../engineering/SECURITY_MODEL.md).

Any future AI proposal requires a new documented feature decision and data-flow/security/privacy review before code or data access is added. The owner must then create a system-specific risk register, mitigations, evaluation, human escalation, and tested disable/rollback plan. No AI owner or kill switch is currently designated.
