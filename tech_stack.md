# Tech Stack

## Approved Stack
- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Vanilla CSS (`src/index.css`) with custom CSS variables
- **Icons**: `lucide-react`
- **Linting**: `oxlint`

## Significant Dependencies
- `lucide-react`: Used for clean, consistent iconography matching the premium aesthetic.
- `react`, `react-dom`: Core UI library.
