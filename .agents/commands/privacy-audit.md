# Privacy Audit Command

**Action:** Audits the system for privacy risks and updates data inventory.

**Usage:** Run this command to ensure privacy compliance.

## Steps:
1. Agent builds/updates the data inventory.
2. Agent scans for PII/secrets risk in logs, analytics, tests, error messages, AI prompts, storage, and third-party calls.
3. Agent identifies required updates to the Privacy Policy.
4. Agent strictly avoids making definitive legal-compliance claims.
