# Feature Build Command

**Action:** Implements a planned feature in small, reviewable increments.

**Usage:** Run this command after a feature plan is approved.

## Steps:
1. Agent uses the approved plan.
2. Agent activates `production-coding` and `testing-qa` skills.
3. Agent implements code in small increments.
4. Agent writes/updates tests and documentation alongside code.
5. Agent strictly adheres to security and privacy constraints defined in the plan.
